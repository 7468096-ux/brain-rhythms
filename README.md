# Brain Rhythms / Ритмы мозга

Интерактивный гид по ритмам мозга на английском и русском языках. Статический сайт для Cloudflare Pages.

## Разделы
- **Rhythms**: 5 ритмов (дельта, тета, альфа, бета, гамма), лаборатория частот с бинауральным звуком, микшер ЭЭГ, день по ритмам.
- **Brain**: 3D-мозг (three.js) с активностью ритмов, электроды 10–20, 2D-схема.
- **Science**: хронология открытий; реальная ночная ЭЭГ (гипнограмма, спектрограмма, циферблат, звук ночи); 7 историй из исследований.
- **Age**: ритмы и сон от рождения до 90 лет.
- **Longevity**: факторы риска деменции из отчёта Lancet 2024 и ключевые испытания.
- **Boost**: что улучшает работу мозга по экспериментам.
- **Practice**: таймер дыхания и медитации на 5 техник.
- **Quiz**: 13 вопросов.

## Данные и лицензии
- Ночная ЭЭГ: Sleep-EDF Expanded, запись SC4001 (PhysioNet), лицензия Open Data Commons Attribution v1.0. Kemp et al., 2000, IEEE TBME; Goldberger et al., 2000, Circulation. На странице указана атрибуция.
- Каналы Fpz-Cz и Pz-Oz, 100 Гц, фильтр 0,3–35 Гц. `night.wav` — канал Fpz-Cz за 7 часов, 8 бит, используется для сонификации.
- three.js r128 (MIT) с cdnjs; шрифты Unbounded, Golos Text, JetBrains Mono (SIL OFL) с Google Fonts.
- Все утверждения на сайте снабжены ссылками на статьи (DOI).
